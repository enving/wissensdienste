## How to fill in this form

re. 1: Description of data collection and processing Please describe which data is to be re-used or newly collected in your planned research project, how the data is to be collected, structured, processed and evaluated, which methods are to be used for quality assurance, what volume of data you expect and whether the collected data can be re-used in principle.

Example:

According to current research in the subject-specific data archives (repositories), no data are available that can be used for the questions in the project. For this reason, the following data will be collected:  … In the first year of the trial, larval infestation is quantified on 20 ears/plot/line at development stage XY (BBCH XY). The data is stored with the associated metadata as an Excel file. Data is analysed using the statistical software XY. To ensure data quality, the sampling is repeated in the second year of the trial (identical locations and repetitions). The total volume of data collected in the project is estimated at ... GB.

## re. 2: Data documentation

Please explain how the data will be documented so that it can be re-used. Specify, if available, standards used for data storage, naming, versioning and metadata compilation.

Example 1: The data is stored, named, versioned according to the standards of XY University. The data is stored via the data centre of XY University. Metadata is compiled according to the specifications of the XY repository and is thus machine-readable and interoperable.

Example  2: The standards for data storage, naming, versioning and the compilation of metadata will be defined in accordance with the work plan by [date] with the collaborating partners.

## re. 3: Data selection and data archiving

Please explain which project data will be archived for which period. If applicable, which data will not be archived and why not? Note: The data to be archived should primarily be those on which a publication is based or which can be used to verify or reproduce the main results of a project.

Note: According to the rules of good scientific practice, research data should be archived in your own institution or in a relevant supra-regional infrastructure for at least ten years.

## Please provide information on the estimated volume of data to be archived and the associated expenses/costs during the project period and afterwards.

Example: Project results shall be published in at least two OpenAccess publications. All relevant project data, including metadata, will be archived and made available in a subject-specific repository (e.g. Repository XY) for a period of ten years. During the duration of the project, we expect to archive a data volume of ... GB. The expenses/costs for data archiving are expected to amount to ... € during the project period. After the end of the project, the volume of data to be archived is estimated at ... GB. The expenses/costs for this will be borne by the research institution.

## re. 4: Availability of research data

Please explain which data will be published and made available for subsequent use at what time. In which repository will the data be archived and which access options will be granted (free, restricted, no access, licensed)? If applicable, explain which data will not be published or made available for subsequent use. For example, there

may be legal (e.g. patent law, copyright), competitive or ethical aspects that make it impossible to make the data available.

Example 1: With the publication of project results, but at the latest along with the final report six months after the project ended, project data, provided with an identifier (DOI), will be made freely available in the institutional repository of XY University.
