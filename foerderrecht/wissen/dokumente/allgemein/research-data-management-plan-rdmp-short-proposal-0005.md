## Re. 2:  Description of data collection and processing

Please describe which data is to be re-used or newly collected in your planned research project, how the data is to be collected, structured, processed and evaluated, which methods are to be used for quality assurance, what volume of data is expected and whether the collected data can be re-used in principal.

## Example:

According to current research in the subject-specific data archives (repositories), no data are available that can be used to answer the questions in the project. For this reason, the following data will be collected:…… … In the first year of the trial, the larval load is quantitatively determined on 20 ears/plot/row at development stage XY (BBCH XY). The data is stored together with the associated metadata as an Excel file. The data is analysed using the statistical software XY. To ensure data quality the sampling is repeated in the second year of the trial (identical locations and repetitions). The total volume of data collected in the project is estimated at ...GB.

The dataset for the study of XY may be relevant for other research disciplines/institutes. The data and metadata will therefore be made available for subsequent use in a subject-specific repository.

## Re. 3: Data documentation

Please explain how the data will be documented so that it can be re-used. Please specify, if available, the standards, if any, used for data storage, naming, versioning and metadata compilation.

Example 1: The data is stored, named, versioned in accordance with the standards of the University of XY. The data is stored via the data centre of the University of XY. Metadata is compiled according to the specifications of the XY repository and is thus machine-readable and interoperable.

Example 2: The standards for data storage, naming, versioning and the compilation of metadata will be defined in accordance with the work plan by [date] with the collaborating partners.

## Re. 4: Data selection and data archiving

Please explain which project data will be archived for which period. If applicable, which data will not be archived and why not?

Note: The data to be archived should primarily be those on which a publication is based or which can be used to verify or reproduce the main results of a project.

Note: According to the rules of good scientific practice, research data should be archived in your own institution or in a relevant supra-regional infrastructure for at least ten years.

Please provide details of the estimated volume of data to be archived and the associated expenditure/ costs during the project period and afterwards.

Example: Project results  shall  be  published  in  at  least  two  Open  Access  publications.  All  relevant  project  data, including metadata, will be archived and made available in a subject-specific repository (e.g. Repository XY) for a period of ten years.

During the project period ,  we expect to archive a data volume of ... GB. The expenses/costs for data archiving are expected to amount to ... € during the project period.

After the end of the project , the volume of data to be archived is estimated at ... GB. The expenses/costs for this will be borne by the research institution.
